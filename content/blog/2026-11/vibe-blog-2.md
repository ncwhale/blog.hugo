## 主题重新设计！

刚刚在 Twitter 上看到了 [这个SKill: gemini-frontend-design](https://www.skills.sh/google-gemini/demolab/gemini-frontend-design) ，简单来说就是一个教哈基米怎么做现代页面的指南，于是我也喂给了哈基米4 Neon，然后让她重新设计了 KuroAka 这个主题。有请 Gemini 来补充设计更改细节！

> 接过笔！这次翻新不是推倒重来，而是保留 KuroAka 原有的**黑、红、白直角建筑感**、HTMX 无刷新导览和零 JS 移动端菜单，对照 `gemini-frontend-design` 的规范把视觉噪声减掉、把版式和排版拉齐。具体改了下面这几件事：

1. **去掉“灰底套盒”，改用全宽画廊白底与单行吸顶导航**
   - 旧版页面被包在一个 `1140px` 的灰底阴影方框里，导航栏挂在头图下面。新版直接去掉外框，让页面铺满视口，顶部放置单行吸顶黑色导航栏（左侧是带小红点标记的品牌字标，右侧是清晰的单行菜单），滚动时用 `2px` 品牌红底线与正文干净隔开。
   - 博客的核心是内容而不是全屏广告首图，所以整体压缩了头部高度，桌面端一打开首屏就能直接看到最新文章和侧边栏。

2. **头图去霓虹与超宽屏构图适配**
   - 去掉了之前标题上持续呼吸闪烁的霓虹发光动画，改用简洁的高对比白色展示字体配左侧 `4px` 品牌红竖线。
   - 实测超宽屏时发现头图被横向拉伸会裁掉人物表情，原图边缘还带有一点白边。于是把头图收束在与正文同宽的 `1160px` 区域内轻微裁边，并在左右两侧叠加向纯黑顶栏（`#141416`）过渡的渐隐遮罩——不管普通屏幕还是带鱼屏，看板娘的眨眼表情都能完整露出，左侧文字也有足够的对比度。

3. **严格的两字体搭配与三档正文字号**
   - 字体从原本的 Open Sans 切换为几何感更强的 `Space Grotesk`（标题与品牌）搭配 `Inter` + 系统中文无衬线（正文与 UI，等宽字体只留给代码块）。
   - 把之前散落在样式表里的 10 多种字号统一收束成正文 **3 档**（`22px` / `16px` / `14px`，全站零 `< 13px` 小字），取消了导航、按钮和侧边栏标题的强制全大写（`ALL CAPS`），为日期、计数与页码开启等宽数字（`tabular-nums`），并将单篇文章阅读栏宽度控制在 `68ch`。

4. **消除嵌套卡片框与“按钮墙”**
   - 文章列表和侧边栏小组件不再各自套一层边框盒，改用留白与 `1px`/`2px` 细线划分层级；文章项悬停时左侧浮现一条细红线提示焦点。
   - 移除了侧边栏社交链接、文章标签和 `/tags/` 索引里成排的实心黑块按钮，改为清爽的文字排版链接；底部分页也把原本红底实心的 `1 / 14` 页码改成了带红色下划线的纯数字排版，只让真正可点击的翻页方钮保留边框交互。

5. **评论区（`hx-echo`）排版打磨与边界加固**
   - 把每条评论右侧成排的带框「回复」按钮改为轻量纯文字操作，让底部的「发表评论」成为评论区唯一的主操作按钮；输入框改为白底线框，桌面端将昵称框收束为 `280px`，聚焦时在输入框左侧亮起 `3px` 品牌红内嵌竖线。
   - 针对真实 Markdown 评论做了边界加固：修复了回复中 `@某人` 换行断层与多段回复段距塌陷，把评论内 `# 标题` 限制在正文字号避免喧宾夺主，并为宽表格、长代码块和超长无空格用户名补齐了独立横向滚动与自动折行。

以上就是这次 KuroAka 的设计翻新笔记，笔还给博主喵！

## 整理了 TAG 和 Category

由于博客实际上存在的历史比技术还悠久了（快20年了），最早是 Wordpress （对，就是前几天被炸了好几个大漏洞那个），之后随着 V8 兴起和 Nodejs 的加入换过一段时间 Ghost，最后还是全面静态化的 Hugo 更得我心。但是这一路下来，老的博文虽然是保留了但很多 META 信息缺失了，比如应该有的 TAG 和 分类。

于是又叫哈基米来帮忙了喵！结果连 5小时额度的 1% 都没用掉，几百篇博文就被整理好了喵！也！太！快！喵！下面有请 Gemini 讲讲怎么做到的：

> 再次接过笔！面对横跨近 20 年的历史博文，硬靠手工一篇篇翻肯定会头晕眼花，所以这次走的是**「脚本体检 → 对齐规范 → 逐篇映射 → 批量写入并验货」**的流水线：
>
> 1. **全量体检摸底**：先用一段纯 Python 脚本扫描 `content/blog` 下全部 **138 篇** `.md` 文章，提取每篇的 YAML frontmatter 和正文摘要。一查发现：119 篇没有分类、104 篇没有标签；原有的 5 个分类中英混杂（`Tool`、`Service`、`Science`、`教程`、`日常`），66 个标签里则混着大小写重复（`Blog`/`BLOG`）、中英重复（`Tool`/`工具`）、一次性碎片词，甚至还有复制模板漏改的误标（比如 K8s 集群草稿顶着 `Samba`/`ZFS`/`NFS` 的标签）。
> 2. **先定体系再动手**：和博主确认了三项规则——覆盖全部 138 篇、将分类统一收束为 **5 个中文主分类**（`技术`、`日常`、`游戏与ACG`、`创作`、`收藏与杂谈`），标签采用高复用精简模式，避免满屏只有 1 篇文章的孤立标签。
> 3. **逐篇按内容重标与细节保留**：通读全部文章标题与摘要后，为 138 篇逐一分配了 1 个主分类和 1–4 个规范标签，把重复项和同义词合并收敛为 **43 个**高复用标签（同时修正了误标文章）。对于三篇「三题作文」，把原本散落在 TAG 里的题面关键词（如 `眨眼 / 悖论 / 便利贴`）统一归到 `三题作文`，并贴心地以引用块补回每篇文章的文末，既清爽又不丢创作背景。
> 4. **脚本精准回写与构建验证**：用脚本先跑了一遍 dry-run 核对 138 篇无遗漏、分类与标签分布均衡后，才只针对 frontmatter 的 `categories` 和 `tags` 两行做精确替换（保留原有正文、其他元数据和 CRLF 换行），最后跑 `hugo` 全站构建验证 236 个页面零报错收工。
>
> 笔再还给博主喵！
